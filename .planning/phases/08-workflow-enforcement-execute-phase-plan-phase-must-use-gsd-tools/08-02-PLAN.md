  <action>
  Modify `searchPhaseInDir` (line ~4094) to add a fuzzy matching fallback when the exact `startsWith` match fails.

  **Current logic (line 4098):**
  ```javascript
  const match = dirs.find(d => d.startsWith(normalized));
  if (!match) return null;
  ```

  **Replace with:**
  ```javascript
  let match = dirs.find(d => d.startsWith(normalized));
  let matchStrategy = 'exact';

  if (!match) {
    // Fuzzy fallback: strip leading zeros from both sides and match on numeric prefix
    const normalizedNum = normalized.replace(/^0+/, '') || '0';
    match = dirs.find(d => {
      const dirNum = d.match(/^0*(\d+(?:\.\d+)?)/);
      return dirNum && dirNum[1] === normalizedNum;
    });
    if (match) {
      matchStrategy = 'fuzzy';
    }
  }

  if (!match) return null;
  ```

  **Add matchStrategy to the return object** (inside the return statement at line ~4121):

  Add `match_strategy: matchStrategy,` to the returned object, after `found: true,`.

  This ensures:
  - Looking for "21" (normalized to "21") matches dir "21-foo" (exact) or "021-foo" (fuzzy)
  - Looking for "021" (normalized to "21") matches dir "21-foo" (exact via startsWith("21")) — this already works
  - Looking for "21" when dir is "0021-foo" matches via fuzzy (strip zeros: "21" === "21")
  - Exact match is always preferred (tried first)
  - matchStrategy is logged in the returned JSON for debugging

  IMPORTANT: Do NOT change the normalizePhaseName function (line 242). Do NOT change findPhaseInternal. Only modify searchPhaseInDir.

  IMPORTANT: The fuzzy match must extract the numeric prefix from directory names using the same pattern as the existing regex on line 4101 (`/^(\d+(?:\.\d+)?)-?(.*)/`), but strip leading zeros for comparison.
