<objective>
Rewrite all negative instructions to positive framing in the 10 agent files in the `agents/` root directory (~33 instances of "don't", "never", "do NOT", "must not", "avoid").

Purpose: Negative framing ("don't do X") causes LLMs to fixate on the prohibited behavior. Positive framing ("do Y instead") guides toward desired behavior more reliably. This is a well-established prompt engineering principle.
Output: 10 agent files with all negative instructions converted to positive equivalents.
</objective>

  <action>
  For each file, find every instance of "don't", "never", "do NOT", "do not", "must not", "avoid" that is an INSTRUCTION (telling Claude what to do/not do).

  Skip these — they are NOT instructions to rewrite:
  - Markdown headings or section titles (e.g., "## Do NOT")
  - Text inside code blocks (``` delimited)
  - Example content showing what users might write
  - Descriptive text explaining what something does (e.g., "this avoids race conditions")

  For each instruction found, rewrite using positive framing:

  Conversion patterns:
  - "Don't use X for Y" → "Use Z for Y. Reserve X for W."
  - "Never skip X" → "Always run X before proceeding."
  - "Do NOT include X" → "Include only Y and Z."
  - "Avoid X" → "Prefer Y instead." or "Use Y for better results."
  - "Must not X" → "Keep X unchanged." or "Preserve X as-is."
  - "Don't commit X" → "Run Y before every commit."

  Preserve the original behavioral intent exactly. The instruction should produce the same Claude behavior, just framed positively.

  Important: "Do NOT" section headers at the end of files (like constraint lists) should become "Constraints" or "Guardrails" sections with positively-framed rules inside.
  </action>
